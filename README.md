# CameraVision

Локальная программа на Python: смотрит в камеру, находит объекты и людей,
показывает рамки и пытается угадать **вид растения** или **модель устройства**
(ноутбук, мышь, автомобиль). Всё считается на вашем компьютере, без облака.

![пример](assets/bus_annotated.jpg)

## Что умеет

- **Объекты COCO** — 80 классов: человек, ноутбук, мышь, комнатное растение,
  чашка, телефон, стул, автомобиль и т. д. (YOLO11, обученная на COCO).
- **Люди** — рамка, устойчивый ID, поиск лиц (каскад Хаара), цвет одежды,
  положение в кадре и грубая дистанция.
- **Модели и виды** — zero-shot CLIP сравнивает вырезанный объект со списком
  из [`labels/finegrained.json`](labels/finegrained.json):
  `MacBook Pro`, `ThinkPad`, `MX Master`, `Монстера`, `Орхидея`, `Camry`…
  Показываются top-3 гипотезы с вероятностями.
- **Честная неуверенность** — если объект похож на «ноутбук вообще», а не на
  конкретную модель, программа пишет «не уверен», а не выдаёт случайную марку.
- **Видео и IP-камеры** — веб-камера, файл, `rtsp://`, `http://…m3u8`, картинка/URL.
- **Запись** — размеченное видео (mp4), снимки по клавише, JSONL для интеграций.

> ⚠️ CLIP не читает логотипы и не является базой моделей. «MacBook Pro 34%» —
> это предположение по форме и цвету, а не точная идентификация. Для растений
> точность тоже ориентировочная: списки легко расширить под свои задачи.

## Быстрый старт (Windows)

```powershell
# один раз: окружение и зависимости
.\setup.ps1

# камера
.\run.ps1 --source 0
```

Или вручную:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe detect.py --source 0
```

Первый запуск скачивает веса YOLO (~5 МБ) и CLIP (~350 МБ). Дальше — офлайн.

Проверка окружения и камер:

```powershell
python detect.py --doctor
python detect.py --list-cameras
```

## Примеры

```powershell
# веб-камера, окно с панелью
python detect.py --source 0

# IP-камера (RTSP)
python detect.py --source "rtsp://user:pass@192.168.1.64:554/Streaming/Channels/101"

# одно фото или ссылка
python detect.py --image photo.jpg --save out.jpg
python detect.py --image "https://example.com/room.jpg" --headless

# видеофайл + запись результата + JSONL
python detect.py --source video.mp4 --record recordings/out.mp4 --jsonl recordings/out.jsonl

# быстрый режим на слабом CPU
python detect.py --source 0 --imgsz 480 --fg-every 2

# без CLIP (только детекция и люди)
python detect.py --source 0 --no-fine-grained
```

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `q` / `Esc` | выход |
| `s` | снимок в `snapshots/` |
| `f` | включить/выключить CLIP |
| `h` | панель со списком объектов |
| `m` | зеркало (селфи-режим) |
| `пробел` | пауза |
| `r` | сбросить трекер |

### Полезные параметры

| Параметр | Смысл |
|---|---|
| `--source 0` | номер камеры, файл или URL потока |
| `--model yolo11n.pt` | модель YOLO; можно `.onnx`, `.engine`, `yolo11s.pt` |
| `--imgsz 640` | вход детектора: 480 быстрее, 960 точнее |
| `--conf 0.35` | порог уверенности детектора |
| `--device cpu` / `0` | CPU или GPU (CUDA) |
| `--detect-every 2` | детекция раз в 2 кадра (быстрее, рамки чуть запаздывают) |
| `--no-fine-grained` | выключить CLIP |
| `--fg-model`, `--fg-pretrained` | другая модель open_clip |
| `--fg-topk 3` | сколько гипотез показывать |
| `--fg-margin` | насколько конкретная гипотеза должна обогнать «просто объект» |
| `--labels path.json` | свой список видов/моделей |
| `--no-faces` | не искать лица |
| `--headless` | без окна (сервер, запись, JSONL) |
| `--record out.mp4` | записать размеченное видео |
| `--jsonl out.jsonl` | результаты в JSONL |
| `--frames N` | остановиться через N кадров |
| `--benchmark N` | измерить FPS на N кадрах без окна |

## Как это работает

1. **YOLO11** (Ultralytics) находит объекты и отдаёт рамки/классы.
2. **IoU-трекер** присваивает устойчивые ID: объект можно называть «#2 ноутбук».
3. **CLIP** (`open_clip`, ViT-B-32) получает вырезанный объект и сравнивает его
   с текстовыми описаниями из `labels/finegrained.json`, усредняя 4 кадра.
   Дополнительно считается сходство с обобщённым описанием («a laptop»):
   если разница мала, результат помечается как неуверенный.
4. **Каскад Хаара** ищет лица внутри рамок людей; цвет одежды берётся из
   верхней половины силуэта.
5. Всё рисуется на кадре: рамки, подписи, панель, FPS и задержка.

Если CLIP не установлен или нет интернета, программа продолжает работать:
для растений остаётся цветовая эвристика (например, «возможен цветок (красный)»).

## Свои виды и модели

Откройте `labels/finegrained.json` и добавьте запись:

```json
{
  "ru": "Мой кактус",
  "en": "a small round cactus with yellow flowers in a terracotta pot"
}
```

- `ru` — подпись на экране;
- `en` — описание для CLIP (по-английски, с визуальными признаками);
- `targets` — какие классы COCO проверять этим списком;
- `margin` — насколько гипотеза должна быть ближе, чем «объект вообще»
  (больше — строже, меньше — смелее).

Новые группы добавляются так же: скопируйте блок в `groups`, задайте
`key`, `targets`, `kind` (`product` / `plant` / `car`) и `labels`.

## Производительность

На CPU YOLO11n при `--imgsz 640` даёт примерно 5–12 FPS, CLIP добавляет
~50–100 мс на объект (только первые кадры, дальше кэш). Что помогает:

- `--imgsz 480` или `--imgsz 416`;
- `--detect-every 2`;
- `--no-fine-grained`, если модели не нужны;
- GPU: `--device 0` (нужна CUDA-сборка torch);
- камера 1280×720 вместо 4K: `--width 1280 --height 720 --fps 30`.

## Интеграция

JSONL — одна строка на кадр:

```json
{"ts": 1730000000.0, "frame": 42, "source": "камера #0", "people": 1,
 "objects": [{"id": 3, "class": "laptop", "ru": "ноутбук", "confidence": 0.91,
 "bbox": [120, 80, 420, 310], "model": [{"name": "Apple MacBook Pro", "score": 0.41,
 "source": "clip"}], "model_uncertain": false}]}
```

## Ограничения

- Класс `mouse` в COCO — это **компьютерная мышь**. Живую мышь COCO не знает;
  для животных/произвольных объектов нужна open-vocabulary модель
  (например, YOLO-World) — её можно подключить вместо `--model`.
- CLIP путает похожие модели и сорта; списки и `margin` стоит подгонять
  под свои объекты.
- Лица ищутся каскадом Хаара: хорошо при фронтальном свете, хуже в профиль.
- Определение пола/возраста и биометрия намеренно не делаются.
- Приложение не заменяет систему безопасности и не гарантирует точность.

## Структура

```
detect.py                 точка входа
camvision/
  cli.py                  аргументы, цикл камеры, горячие клавиши
  sources.py              веб-камера, файлы, RTSP/HTTP, картинки
  detector.py             YOLO + структура Detection
  tracker.py              IoU-трекер и Track
  finegrained.py          CLIP zero-shot, списки, эвристики
  faces.py                лица, одежда, положение, дистанция
  pipeline.py             сборка кадра и кэширование гипотез
  drawing.py              рамки, подписи, панель (кириллица через Pillow)
  output.py               JSONL, видео, снимки
labels/finegrained.json   редактируемые списки моделей и видов
tests/test_core.py        14 тестов без камеры и весов
```

## Частые проблемы

| Симптом | Решение |
|---|---|
| Камера не открылась | закройте Zoom/Teams/браузер, проверьте разрешение камеры в Windows, попробуйте `--source 1` |
| `--list-cameras` ничего не находит | камера занята или отключена в диспетчере устройств |
| Долго первый запуск | скачиваются веса YOLO/CLIP; дальше они в `models/` и `.cache/` |
| Нет интернета | скачайте `yolo11n.pt` вручную в `models/` и укажите `--model models/yolo11n.pt`; CLIP отключится сам |
| Окно не открывается | запустите с `--headless`, проверьте, что установлен `opencv-python`, а не `opencv-python-headless` |
| Мало FPS | `--imgsz 416 --detect-every 2`, закройте другие программы |
| Русский текст «квадратиками» | установите Pillow; программа возьмёт `segoeui.ttf`, иначе перейдёт на латиницу |
